# WTE QOL Template

Мод для **Welcome to Elderfield** (RPG Maker MZ): <одно предложение — что делает мод>.

## Что даёт

- <фича 1 — что видит игрок>

Мод не правит файлы игры: отключение возвращает полностью оригинальную игру.

## Требования

- Welcome to Elderfield 1.0.4d с официальным меню модов (точная ревизия мода — `1.0.4d.1`).
- Обновления игры могут затереть папку `mods/` — после обновления просто скопируй мод заново.

## Установка

1. Распакуй архив в папку игры так, чтобы `WTE_QOL_Template` оказалась внутри `<игра>/mods/`.
2. Запусти игру и открой «Настройки → Mods» из главного меню. Проверь, что мод отображается с правильными версиями игры и мода. Ручная правка `js/plugins.js` не нужна.
3. При первом запуске лоадер может пересобрать инъектор и один раз перезагрузить игру.

Для отключения переименуй папку, добавив префикс `!`: `!WTE_QOL_Template`.

## Настройка

Все настройки — в объекте `CONFIG` в начале `js/plugins/mod_template.js` (мод-плагины не видны в PluginManager):

| Настройка | По умолчанию | Что делает |
|---|---|---|
| `DEBUG` | `false` | подробные DEBUG-строки в логе |

## Логи для диагностики

Мод всегда пишет в `mods/WTE_QOL_Template/logs/mod_template.log` (папка создаётся автоматически): запуск с версией и конфигом, <что ещё>, и любые ошибки. Если что-то сломалось — приложи этот файл к репорту. Лог обрезается при росте за 1 МиБ.
