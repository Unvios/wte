# AGENTS.md — моддинг Welcome to Elderfield

Репозиторий — моды для игры Welcome to Elderfield (RPG Maker MZ, рантайм NW.js).
Игровая сборка целиком в git; моды живут в `mods/`, база знаний — в `docs/`.

## С чего начать (в порядке чтения)

1. `docs/README.md` — оглавление и базовые факты движка.
2. `docs/mod-loader.md` — как грузятся моды: инъекция плагинов, splice-формат, приоритеты.
3. Задача связана со временем/баффами → `docs/timed-states.md`.
4. Задача касается текстов/перевода → `docs/localization.md` (обязательно: там
   неочевидные пути перевода и проверенный паттерн обёрток).
5. Официальный гайд разработчиков: `mods/How to Mod.txt` (дублирует docs/mod-loader.md).

Эталон реализации всех паттернов: `mods/WTE_QOL_Coffee_Duration/`
(таймер состояния + многоязычные тексты через обёртки).

## Железные правила

- **Не править оригинальные файлы игры.** Единственное задокументированное
  исключение: `js/plugins.js` → `VirtualModLoader` включён (`status: true`) —
  без него моды не грузятся вообще. Файл игры в репозиторий не коммитим
  (правка теряется при обновлении — восстанавливать скриптом
  `tools/enable_mod_loader.sh`). Обновления также могут затереть `mods/` —
  поэтому моды и доки держим в git.
- Новый мод = новая папка `mods/<ModName>/` с `mod.json`
  (`name`, `author`, `version`, `description`, `priority`).
- Плагины модов: оборачивать в IIFE, алиасы называть `alias_<Класс>_<метод>`,
  конфигурацию хардкодить внутри файла — `PluginManager.parameters()` для
  мод-плагинов не работает.
- Данные менять через splice (`data/modded<Имя>.json`), НЕ полными копиями
  базовых файлов. Помнить: элемент массива заменяется целиком по `id`.
- Строки, существующие в `game_messages.csv`, не менять в `data/*.json` —
  сломаются ключи локализации. Использовать паттерн обёрток из
  `docs/localization.md`.

## Окружение и инструменты

- Windows + Git Bash. `node`, `python`, `jq` в PATH отсутствуют.
- Валидация JSON: `perl -MJSON::PP -e '...'`.
- Поиск по коду: `grep`/ripgrep; учесть, что VisuMZ-*.js обфусцированы —
   смысл из них не вытащить, методы патчатся «слепо» по именам классов MZ.

## Проверка модов

1. Запустить `Game.exe` — лоадер сам пересобирает `js/plugins/ModLoader_Injector.js`
   и один раз перезагружает игру.
2. Консоль (F12/Ctrl+Shift+I): логи лоадера с тегом `[Mod Loader]`, наш
   эталонный мод пишет `[CoffeeDuration]`.
3. Ачивки Steam модами не отключаются (проверено: `Cyclone-Steam.js` шлёт
   `greenworks.activateAchievement()` безусловно).

## Структура репозитория

- `mods/` — моды (`!`-префикс = выключен). В git трекаются только свои моды
  с префиксом `WTE_QOL_*` (правило `!/mods/WTE_QOL_*/`); чужие моды из
  `mods/` в репозиторий не попадают. Для своего мода с другим именем добавь
  исключение в `.gitignore`.
- `docs/` — документация по движку (см. выше).
- `tools/` — вспомогательные скрипты (`enable_mod_loader.sh` — вернуть
  работу модов после обновления игры).
- `AGENTS.md` — этот файл-навигатор.
- `js/plugins.js` и всё остальное — файлы игры, в репозиторий не попадают.
