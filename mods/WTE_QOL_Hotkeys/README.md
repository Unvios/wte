# WTE QOL Hotkeys

Мод для **Welcome to Elderfield** (RPG Maker MZ): десять слотов быстрого
использования на клавишах **1–9, 0** — для предметов, навыков и ритуалов,
плюс горячие клавиши комплектов снаряжения.

## Как пользоваться

- **Привязка предметов**: в инвентаре наведите курсор на предмет и нажмите
  цифру. **Привязка навыков/ритуалов**: то же самое в меню навыков.
  Повторное нажатие той же цифры на том же объекте снимает привязку; новый
  объект на занятой клавише замещает старый (с него привязка снимается).
  Значок клавиши появляется сразу, в правом верхнем углу иконки.
  Не привязываются (звук ошибки): ключевые предметы, «только из меню»
  (кроме белого списка, см. конфиг — кофе разрешён по умолчанию), предметы
  и навыки с целью «мёртвый союзник», пассивные/служебные навыки без типа.
- **Использование**: на карте — когда персонаж свободно перемещается
  (не во время сообщений/событий); в бою — когда текущий герой ждёт команды,
  использование тратит его ход, навыки тратят MP. Навык может использовать
  только тот, кто его изучил (как в меню). Эффекты, общие события и лог
  работают как из меню.
- **Комплекты снаряжения**: зажмите **Ctrl + цифра** на карте — на текущем
  герое применится комплект из мода WTE_EquipmentLoadouts (проверка
  инвентаря, как в меню комплектов). Пустой комплект — звук ошибки. После
  смены — тост с названием комплекта.
- **Уведомления**: при каждом использовании и смене комплекта по центру
  снизу показывается тост «Использовано: / Надето: + название» (иконка +
  текст), внешне как при поднятии травы/грибов; префикс переведён на все
  языки игры, название берётся из базы данных.
- **HUD**: в левом нижнем углу экрана: иконка предмета или навыка,
  количество — в правом нижнем углу иконки (только предметы), цифра
  клавиши — по центру под иконкой. Непригодное сейчас (нет в наличии,
  не хватает MP, навык не изучен) — серым. Слот без привязки не рисуется.
  Пока открыто окно диалога, панель перекрывает его (HUD рисуется под
  окнами).

Привязки сохраняются в сейвах. Никакие файлы игры не изменяются —
мод выключен = игра оригинальная целиком.

## Как это устроено

Плагином `js/plugins/hotkeys_consumable.js`. Биндинг — обработка цифр в
`Scene_Item`/`Scene_Skill` над списками; использование на карте
воспроизводит `Scene_ItemBase.useItem` (трата/эффекты/общие события), в бою
подключается к штатному боевому флоу через `BattleManager.inputtingAction()`
(трата хода, лог боя — как из меню). Комплекты — логика
`Scene_Equip.prototype.onLoadoutEquip`, применённая к `menuActor()` без UI.
Тосты — `CGMZ_ToastManager`, те же параметры, что у тоста поднятия предмета
(CE 2838); названия переводятся из базы данных, префиксы «Использовано:»/
«Надето:» — из таблицы TEXTS на всех языках игры. Панель HUD — спрайт в
левом верхнем углу в слое SRD HUD Maker Ultra.

Подробный разбор: [`docs/hotkeys-consumable.md`](../../docs/hotkeys-consumable.md).

## Конфигурация

Все настройки — объект `CONFIG` в начале `js/plugins/hotkeys_consumable.js`
(мод-плагины не видят менеджер плагинов игры):

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `SLOT_KEYS` | `['1'…'9','0']` | клавиши слотов |
| `LOADOUT_MODIFIER` | `'control'` | модификатор комплектов (Ctrl+цифра) |
| `EXTRA_ITEM_IDS` | `[2043]` | id предметов, биндимых несмотря на «только из меню» (кофе). Очистите для строгого правила игры |
| `TOAST.WIDTH` / `TOAST.DISPLAY_TIME` | `360` / `180` | ширина и время показа тоста |
| `HUD.LEFT` / `HUD.BOTTOM` | `8` / `8` | положение панели (левый нижний угол; во время диалогов её перекрывает окно сообщения) |
| `HUD.SLOT_WIDTH` / `HUD.HEIGHT` | `40` / `52` | размеры панели (10 слотов = 400px) |
| `LOG_DIR` / `LOG_FILE` | `logs` / `hotkeys_consumable.log` | журнал внутри папки мода (в git не попадает). Ротация при >1 МБ |
| `DEBUG` | `false` | подробные внутренние логи; обычные события пишутся всегда |

## Журнал диагностики

Всё операционное пишется всегда (не зависит от `DEBUG`) в
`mods/WTE_QOL_Hotkeys_Consumable/logs/hotkeys_consumable.log` с таймстампами:
запуск мода с конфигурацией, бинды/снятия, использования, **отказы с
причинами** (остаток, occasion, MP, `testApply`, whitelisted и т.п.),
применение комплектов (включая недостающие предметы), ошибки со
стектрейсами. Лог живёт в папке мода — при передаче мода другому человеку
журнал едет вместе с ним, и по нему можно понять, что именно у него не так.
Папка `logs/` исключена из git.

## Установка и отключение

Папка мода кладётся в `mods/WTE_QOL_Hotkeys/` (уже сделано).
Лоадер игры сам подхватит её при следующем запуске `Game.exe`.
Для отключения добавьте `!` в начало имени папки: `!WTE_QOL_Hotkeys`.

**Внимание:** обновления игры стирают папку `mods/` — держите копию
(например, этот git-репозиторий).
