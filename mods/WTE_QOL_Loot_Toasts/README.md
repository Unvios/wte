# WTE QOL Loot Toasts

Мод для **Welcome to Elderfield** (RPG Maker MZ): убирает блокирующие окна
после боя и заменяет их неблокирующими тостами. Управление возвращается
сразу после броска кубика — прокликивать ничего не нужно.

## Что вы видите после боя

- **Сводный тост наверху стека** (справа, внизу экрана): грань выпавшего
  кубика (оригинальный арт игры), полученный опыт и золото одной строкой,
  например `[грань]  50 ОП  24🪙`. Чего не выпало — того в строке нет.
- **Предметы** тостами под ним: иконка + локализованное название (+ `xN`,
  если больше одного). Слово «Получено» не выводится — ни на одном языке.
- **Награда боевых святилищ** — те же тосты предметов, но с золотой рамкой;
  внизу стека. Текст «Святилище награждает вас…» не показывается.
- Порядок чтения сверху вниз всегда: **сводный тост → обычные предметы →
  предметы святилища**. Новый бой подменяет лут-тосты предыдущего (свежий
  результат важнее недочитанного).
- Больше не появляются окна: «Появляется крыса!» / «Нападает милый цветок!»
  (начало боя), «Труп цел / изуродован», «Победа! Получено: N ОП».

Всё вне боёв (сундуки, квесты, диалоги, рыбалка, обычные святилища)
работает как в ваниле. Никакие файлы игры не изменяются — мод выключен =
игра оригинальная целиком.

## Как это устроено

Плагином `js/plugins/loot_toasts.js`. После победы игра запускает общее
событие 27 «Battle Win» с ~40 лут-таблицами; мод распознаёт эту цепочку и:

- перехватывает все окна сообщений внутри неё (сообщения копятся в батч
  и выводятся одной сортированной пачкой по её окончании);
- собирает тексты дропа из данных (id предмета/сумма из переменных
  события) — поэтому локализация бесплатно берётся из базы предметов;
- пропускает анимацию броска кубика, картинки лута и звуковые паузы.

Подробный разбор: [`docs/loot-toasts.md`](../../docs/loot-toasts.md).

## Конфигурация

Все настройки — объект `CONFIG` в начале `js/plugins/loot_toasts.js`
(мод-плагины не видят менеджер плагинов игры):

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `TOAST_DISPLAY_TIME` | `180` | время показа тоста, кадры (3 с) |
| `TOAST_WIDTH` | `380` | ширина тоста, px |
| `RIGHT_MARGIN` | `8` | отступ стека от правого края, px |
| `MAX_TOAST_SLOTS` | `7` | слотов под тосты (у игры по умолчанию 3) |
| `SUMMARY_SEPARATOR` | `'  '` | разделитель частей сводного тоста |
| `SHRINE_FRAME_COLOR` | `0xFFD700` | цвет рамки награды святилища |
| `REMOVE_BATTLE_START_MESSAGES` | `true` | скрывать «Появляется…» в начале боя |
| `VICTORY_EXP_TOAST` | `true` | «Победа!/N ОП» → сводный тост |
| `BATTLE_WIN_CE_ID` | `27` | id общего события победы (см. доку) |
| `DEBUG` | `false` | лог в `loot_toasts_debug.log` (консоль в этой сборке недоступна) |
| `DEBUG_FORCE_SHRINE` | `false` | помечать весь лут как награду святилища (для теста рамки) |

## Установка и отключение

Папка мода кладётся в `mods/WTE_QOL_Loot_Toasts/` (уже сделано). Лоадер
игры сам подхватит её при следующем запуске `Game.exe`. Для отключения
добавьте `!` в начало имени папки: `!WTE_QOL_Loot_Toasts`.

**Внимание:** обновления игры стирают папку `mods/` — держите копию
(например, этот git-репозиторий).
