# WTE QOL Loot Toasts

Мод для **Welcome to Elderfield** (RPG Maker MZ): убирает блокирующие окна после боя и заменяет их неблокирующими тостами. Управление возвращается сразу после броска кубика — прокликивать ничего не нужно.

## Что вы видите после боя

- **Сводный тост наверху стека** (справа, внизу экрана): грань выпавшего кубика (оригинальный арт игры), полученный опыт и золото одной строкой, например `[грань]  50 ОП  24🪙`. Чего не выпало — того в строке нет.
- **Предметы** тостами под ним: иконка + локализованное название (+ `xN`, если больше одного). Слово «Получено» не выводится — ни на одном языке.
- **Награда боевых святилищ** — те же тосты предметов, но с золотой рамкой; внизу стека. Текст «Святилище награждает вас…» не показывается.
- Порядок чтения сверху вниз всегда: **сводный тост → обычные предметы → предметы святилища**. Когда выдаётся лут нового боя, тосты предыдущего мгновенно убираются (свежий результат важнее недочитанного).
- Больше не появляются окна: «Появляется крыса!» / «Нападает милый цветок!» (начало боя), «Труп цел / изуродован», «Победа! Получено: N ОП».

Всё вне боёв (сундуки, квесты, диалоги, рыбалка, обычные святилища) работает как в ваниле. Никакие файлы игры не изменяются — мод выключен = игра оригинальная целиком.

## Как это устроено

Плагином `js/plugins/loot_toasts.js`. После победы игра запускает общее событие 27 «Battle Win» с ~40 лут-таблицами; мод распознаёт эту цепочку и:

- перехватывает старые окна сообщений и новые команды `WTE_LootRollScene.queueLootMessage` (весь дроп копится в батч и выводится одной сортированной пачкой по окончании CE 27);
- подавляет открытие новой отдельной сцены `Scene_WTE_LootRoll`, а выпавшую грань читает из переменной броска;
- собирает тексты дропа из данных (id предмета/сумма из переменных события) — поэтому локализация бесплатно берётся из базы предметов;
- пропускает старую анимацию броска кубика, картинки лута, звуковые паузы и системный тост об изуродованном трупе.

Подробный разбор: [`docs/loot-toasts.md`](../../docs/loot-toasts.md).

## Конфигурация

Все настройки — объект `CONFIG` в начале `js/plugins/loot_toasts.js` (мод-плагины не видят менеджер плагинов игры):

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `TOAST_DISPLAY_TIME` | `180` | время показа тоста, кадры (3 с) |
| `TOAST_WIDTH` | `380` | ширина тоста, px |
| `RIGHT_MARGIN` | `8` | отступ стека от правого края, px |
| `MAX_TOAST_SLOTS` | `7` | слотов под тосты (у игры по умолчанию 3) |
| `SUMMARY_SEPARATOR` | `'  '` | разделитель частей сводного тоста |
| `SHRINE_FRAME_COLOR` | `0xFFD700` | цвет рамки награды святилища |
| `REMOVE_BATTLE_START_MESSAGES` | `true` | скрывать «Появляется…» в начале боя |
| `VICTORY_EXP_TOAST` | `true` | «Победа!/N ОП» → сводный тост |
| `BATTLE_WIN_CE_ID` | `27` | id общего события победы (см. доку) |
| `DICE_ANIMATION_CE_ID` | `28` | id события анимации кубика (пропускается целиком) |
| `DICE_FACE_CE_IDS` | `[29–34]` | id событий граней 1–6 для старого лут-флоу |
| `ROLL_VARIABLE_ID` | `2` | переменная итогового броска в новом флоу (команда игры может передать другую) |
| `SUPPRESSED_PICTURES` | `[5, 11, 12]` | номера картинок лут-потока, которые не показываются |
| `SUPPRESSED_TEXTS` | 3 строки | тексты про состояние трупа — не выводятся |
| `SHRINE_REWARD_TEXT` | `'The combat shrine rewards you...'` | строка-флаг награды святилища |
| `LOG_MAX_BYTES` | `524288` | ротация лога (512 КБ) |
| `DEBUG` | `false` | подробный debug-уровень логов (см. ниже про логи) |
| `DEBUG_FORCE_SHRINE` | `false` | помечать весь лут как награду святилища (для теста рамки) |

## Логи для разбора проблем

Мод всегда пишет лог в `mods/WTE_QOL_Loot_Toasts/logs/loot_toasts.log` (папка создаётся сама, в git не входит). Туда попадают: запуск мода с версией и конфигом, каждый флеш лута (что и в каком количестве), события святилища, фолбэки на ванильные окна и любые необработанные ошибки игры. Если у кого-то «мод сломал игру» — просите этот файл: по меткам `[INFO]` / `[DEBUG]` / `[ERROR]` и временным меткам видно, до чего дошёл мод и где всё упало. `DEBUG: true` добавляет деталей (каждый тост, броски кубика). Файл сам пересоздаётся при 512 КБ.

## Установка и отключение

1. Распакуйте архив в папку игры так, чтобы `WTE_QOL_Loot_Toasts` оказалась внутри `<игра>\mods\`.
2. Запустите `Game.exe` и откройте «Настройки → Mods» из главного меню. В списке должна появиться `WTE QOL Loot Toasts` с версией игры `1.0.4d` и версией мода `1.0.4d.2`. Ручное редактирование `js/plugins.js` не требуется.
3. При первом запуске лоадер может один раз пересобрать инжектор и перезагрузить игру — это нормально.

Чтобы отключить мод, добавьте `!` в начало имени папки: `!WTE_QOL_Loot_Toasts`.

**Внимание:** обновления игры и «проверка целостности файлов» Steam могут стереть папку `mods/` — после обновления верните мод (поэтому держите копию, например этот git-репозиторий).
